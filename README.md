# NPB ledarstöd – pilot

Öppna piloten: https://jsall77.github.io/npb-ledarstod-pilot/

Fristående interaktiv demo inför integration i befintlig Simployer-app. Innehåller förberedda dialoger och fiktiva exempelresultat. Ingen AI-motor eller Simployer-anslutning är aktiverad.

Planer sparas endast i besökarens webbläsare. Coachsamtal och reflektioner sparas inte mellan omladdningar. Använd endast testinnehåll.

NPB:s sju föreslagna ledarskapsprinciper är ett utkast, inte fastställd policy. Offentlig referens: https://noplanb.se/om-oss/.

Publicering sker från main-grenens rot via GitHub Pages.
